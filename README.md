# Personal Inbox Assistant

## Description

A Personal Inbox Assistant that reviews emails in real-time, and sends a telegram report highlighting the prioritized emails from the last week(tbd), in an easy-to-view format.

- Prioritesed emails can be customised to the user's commands.

## How to run:

### Create a virtual environment
python -m venv .venv

### Activate it
### Windows:
.venv\Scripts\activate or .venv\Scripts\activate\ps1 or .venv\Scripts\activate\bat
### Linux / macOS:
source .venv/bin/activate

### Install dependencies
pip install -r requirements.txt
